# djangors-contrib-gis

GeoDjango-equivalent geospatial types (`Point`, `LineString`, `Polygon`, `Geometry`), WKT/EWKT
parsing and formatting, pure-Rust Haversine distance calculation, and PostGIS SQL lookup helpers
(`ST_DWithin`, `ST_Contains`, `ST_Within`, `ST_Intersects`, `ST_Distance`) for Djangors.
