Djangors Documentation

CLI Reference (dj)

The dj binary (djangors-cli) is Djangors’s equivalent of Django’s manage.py. Install it from crates.io:

cargo install djangors-cli

Custom Management Commands

Any unrecognized subcommand dj <my-command> [args...] is automatically routed to your project’s binary with DJANGORS_RUN_COMMAND=<my-command>, matching functions annotated with #[management_command].
